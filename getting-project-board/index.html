Getting Your StoryQuest Project BoardCómo conseguir tu Tablero de proyecto StoryQuest

Your team will use a shared Project Board to plan your StoryQuest and keep track of the work as you go. We made a StoryQuest Project Board template to help you get started. To use it for your own project, your team needs its own copy.Tu equipo usará un Tablero de proyecto compartido para planear vuestra StoryQuest y llevar la cuenta del trabajo sobre la marcha. Creamos una plantilla del Tablero de proyecto StoryQuest para ayudaros a empezar. Para usarla en vuestro proyecto, tu equipo necesita su propia copia.

Because the board is made with GitHub Projects, your team needs a shared space in GitHub where that copy can live. GitHub calls this an . For StoryQuest, you can think of it simply as your team's shared space.Como el tablero está hecho con GitHub Projects, tu equipo necesita un espacio compartido en GitHub donde pueda vivir esa copia. GitHub lo llama . Para StoryQuest, puedes verlo simplemente como el espacio compartido de tu equipo.

You only set this up onceEsto se prepara una sola vez

Everyone on the team needs a GitHub account, but only one teammate creates the organization. That person creates the organization, invites everyone else to join, and uses the setup tool to create your team's board. Once everyone has joined, the board is ready for the whole team to use together.Todos en el equipo necesitan una cuenta de GitHub, pero solo un miembro crea la organización. Esa persona crea la organización, invita a los demás a unirse y usa la herramienta de configuración para crear el tablero del equipo. Cuando todos se hayan unido, el tablero queda listo para que todo el equipo lo use en conjunto.

Get everyone ready with a GitHub accountPreparad a todos con una cuenta de GitHub

Everyone who will use the Project Board needs their own GitHub account. It is free. If you already have one, sign in and you're ready for the next step.Todas las personas que vayan a usar el Tablero de proyecto necesitan su propia cuenta de GitHub. Es gratis. Si ya tienes una, inicia sesión y estás listo para el siguiente paso.

click a number to mark that step donehaz clic en un número para marcar el paso como hecho

Sign in or create a GitHub accountInicia sesión o crea una cuenta de GitHub

If you already have a GitHub account, sign in now. If you do not have one yet, use the link below to create a free account.Si ya tienes una cuenta de GitHub, inicia sesión ahora. Si todavía no tienes una, usa el enlace de abajo para crear una cuenta gratuita.

  • If you need an account, open github.com/signup.Si necesitas una cuenta, abre github.com/signup.
  • Follow the sign-up steps to enter your email, choose a username, and create a password.Sigue los pasos de registro para escribir tu correo, elegir un nombre de usuario y crear una contraseña.
  • Complete any verification GitHub asks for, and you're in.Completa la verificación que GitHub te pida, y ya estás dentro.

Only one person continues with the setup below. Everyone else can stop here until they receive an invitation.Solo una persona continúa con la configuración de abajo. Los demás pueden parar aquí hasta recibir una invitación.

Create your team's organizationCrea la organización de tu equipo

One teammate creates the GitHub for the whole StoryQuest team. An organization gives your team a shared place where your copy of the Project Board can live. Only one person needs to do this. The rest of the team will join after.Un miembro crea la de GitHub para todo el equipo de StoryQuest. Una organización le da al equipo un lugar compartido donde puede vivir vuestra copia del Tablero de proyecto. Solo una persona necesita hacer esto. El resto del equipo se unirá después.

Step 2Paso 2

Create the organization on the Free planCrea la organización con el plan Free

In the upper-right corner of GitHub, use the + menu to start a new organization. Choose the free option, then give the organization a name your team will recognize.En la esquina superior derecha de GitHub, usa el menú + para empezar una organización nueva. Elige la opción gratuita y luego ponle a la organización un nombre que tu equipo reconozca.

  • In the upper-right corner of GitHub, click the + button and open its drop-down menu.En la esquina superior derecha de GitHub, haz clic en el botón + y abre su menú desplegable.
  • In that menu, choose New organization.En ese menú, elige New organization (Nueva organización).
  • On the plan screen, choose the Free plan.En la pantalla del plan, elige el Free plan (plan gratuito).
  • On the organization setup screen, enter a name your team will recognize.En la pantalla de configuración de la organización, escribe un nombre que tu equipo reconozca.
  • Complete any verification GitHub asks for.Completa la verificación que GitHub te pida.

What should we name it?¿Cómo lo llamamos?

Choose a simple name that identifies your StoryQuest team: your team name, your StoryQuest's working title, or anything your group will recognize. You can change your StoryQuest's working title later, so don't spend too long picking the perfect name here.Elige un nombre simple que identifique a tu equipo de StoryQuest: el nombre del equipo, el título provisional de vuestra StoryQuest, o lo que tu grupo reconozca. Puedes cambiar el título provisional de la StoryQuest más adelante, así que no dediques demasiado a buscar el nombre perfecto aquí.

Invite your teammatesInvita a tus compañeros de equipo

Now invite the rest of your StoryQuest team to the organization. Each teammate joins that org so they will be able to use the shared Project Board.Ahora invita al resto de tu equipo de StoryQuest a la organización. Cada persona se une a esa organización para poder usar el Tablero de proyecto compartido.

Steps 3–4Pasos 3–4

Creator of the organization now invites each teammateQuien creó la organización ahora invita a cada compañero

  • From your organization's page, choose People near the top.Desde la página de tu organización, elige People (Personas) cerca de la parte superior.
  • On the People page, choose Invite member.En la página People, elige Invite member (Invitar miembro).
  • Search for your teammate using their GitHub username or email address.Busca a tu compañero con su nombre de usuario de GitHub o su correo.
  • Follow GitHub's prompts to send the invitation, then repeat for the rest of the team.Sigue las indicaciones de GitHub para enviar la invitación, y repite con el resto del equipo.

Everyone else: accept your invitationLos demás: acepta tu invitación

Check your email or your GitHub account for the invitation and accept it. Once you accept, you're part of the team's organization. Remember, you don't need to create another organization of your own.Revisa tu correo o tu cuenta de GitHub para encontrar la invitación y acéptala. Cuando la aceptes, formas parte de la organización del equipo. Recuerda, no necesitas crear otra organización propia.

Create your StoryQuest Project BoardCrea tu Tablero de proyecto StoryQuest

Now that your team's organization exists, use the StoryQuest setup tool to create your team's copy of the board from the template we prepared.Ahora que existe la organización de tu equipo, usa la herramienta de configuración de StoryQuest para crear la copia del tablero de tu equipo a partir de la plantilla que preparamos.

Open the StoryQuest setup toolAbrir la herramienta de configuración de StoryQuest

Step 5Paso 5

Run the setup tool for your organizationEjecuta la herramienta para tu organización

Open the setup tool and point it at your team's organization. It creates a StoryQuest Project Board for your team using the template.Abre la herramienta y apúntala a la organización de tu equipo. Crea un Tablero de proyecto StoryQuest para tu equipo usando la plantilla.

What the setup tool doesQué hace la herramienta

You don't need to build the Project Board yourself. The setup tool creates your team's copy with the starting structure and guidance already in place. From there, your team can add its own tasks and use the board to plan the StoryQuest you're making.No tienes que construir el Tablero de proyecto tú mismo. La herramienta crea la copia de tu equipo con la estructura inicial y las indicaciones ya puestas. A partir de ahí, tu equipo puede añadir sus propias tareas y usar el tablero para planear la StoryQuest que estáis creando.

Open your board and get startedAbre tu tablero y empieza

Return to your team's GitHub organization. Near the top of the organization page, open Projects. You should now see your team's StoryQuest Project Board.Vuelve a la organización de GitHub de tu equipo. Cerca de la parte superior de la página de la organización, abre Projects (Proyectos). Ahora deberías ver el Tablero de proyecto StoryQuest de tu equipo.

Screenshot (placeholder) The Projects tab with the finished StoryQuest board.

  • Make sure each teammate can open the board before moving on.Asegúrate de que cada compañero pueda abrir el tablero antes de continuar.

You only need to complete this setup once. From here, the board belongs to your team to use throughout your StoryQuest.Solo necesitas completar esta configuración una vez. A partir de aquí, el tablero es de tu equipo para usarlo durante toda vuestra StoryQuest.
