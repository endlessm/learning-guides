Godot Modding · Tutorial 02

What is a scene? Build one and find out.

In Godot, a scene is a collection of nodes saved together. A scene might be something small, like a platform or a coin, or something big, like an entire level. You can also reuse saved scenes inside other scenes, so you don't have to build the same thing again and again. Let's make one.

Step 1 of 4

What's inside a scene?

Scenes are made of nodes, each with a particular job. For example, Sprite2D displays an image, while AudioStreamPlayer plays sound. Godot includes hundreds of node types you can combine to build different parts of a game.

To build a scene, choose the nodes you need, arrange them in the Scene tree, and save. You can even add other saved scenes inside it, using smaller pieces to build something larger.

Once you save a scene, you can use it again and again without rebuilding it. Need ten platforms? Drag your platform scene into the level ten times. Each one is an instance of the same saved scene.

Change the saved platform later, like its collision shape or its artwork, and every instance you've already placed updates too.

Every node lives inside one other node — its parent. A parent can hold any number of nodes inside it — those are its children. The node at the top of the whole tree, the one that holds everything else, is called the root. (The root doesn't have a parent — it's at the top.)

This isn't just a way of organizing things. It changes how the nodes behave together.

Parent moves, children follow. OurPlatform is the root of this scene. Its StaticBody2D and Sprite2D are children, and the CollisionShape2D belongs to the StaticBody2D. Move the root and the whole platform moves together — the sprite and the collision ride along automatically. The same idea applies when you place this scene inside a larger scene.

You've built a platform scene with a root node and three additional nodes. Once saved, you can place it anywhere in your game.

We're using icon.png because it's already in the project. You can replace it with another image without changing the platform's collision.

What does each node do?

StaticBody2D makes the platform solid and stationary. CollisionShape2D defines where the player can land. Sprite2D displays the artwork. Together, these nodes give the platform its appearance and collision.

Build it in Godot

Use this list as a quick reference while you build your own platform:

  1. Create a new scene. Select Scene > New Scene, choose 2D Scene, and rename the root node OurPlatform.
  2. Add the physics body. Add a StaticBody2D child to OurPlatform, then add a CollisionShape2D beneath it.
  3. Set the collision shape. Select CollisionShape2D and create a RectangleShape2D in the Inspector. Resize the shape to match the platform artwork.
  4. Add the artwork. Select OurPlatform and add a Sprite2D child. Drag icon.png from the FileSystem onto its Texture property in the Inspector.
  5. Save your scene. Press Ctrl+S (Cmd+S on Mac) and save it as OurPlatform.tscn.

Step 3 of 4

Drop it into a level.

Now let's use OurPlatform.tscn in a level. Open main.tscn. You can add your saved platform in two ways, and return to the original whenever you want to make changes.

1
Drag it into the viewport

Drag OurPlatform.tscn from the FileSystem into the center viewport of main.tscn. A new instance appears wherever you drop it. Repeat to place as many platforms as you need.

2
Drag it into the Scene tree

You can also drag OurPlatform.tscn directly into the Scene tree. Godot shows where the instance will be added, giving you more control over how your scene is organized.

3
Edit the original scene

To change the original platform, double-click OurPlatform.tscn in the FileSystem. Make your changes and save. Any instances you've already placed will update too, except for properties you've specifically overridden.

The big idea

Every instance you place stays linked to its original scene. When you save changes to OurPlatform.tscn, its instances update.

The exception: a property you've changed on one specific instance, like its position or Modulate color, keeps your change.

Try it: Place your platform somewhere the player can reach it in main.tscn. Run the game and try landing on it. Then open OurPlatform.tscn, change its artwork, and save. Return to main.tscn to see how the instances update.

Step 4 of 4

What's next.

You've built a scene and placed it in a level. Almost everything you build in Godot is some version of those two moves. Here are three ways to practice.

01

Build a different solid object

Create another scene using the same node structure but different artwork. Choose a collision shape that fits what you've made, such as RectangleShape2D or CircleShape2D.

02

Build a path from your platforms

Place several instances of OurPlatform.tscn at different heights in main.tscn. Try arranging them into a short jumping challenge for your player.

03

Customize one instance

With main.tscn open, select one OurPlatform instance in the Scene tree. In the Inspector, find Modulate under Visibility and change its color. Only that instance will change.

What's the difference? While you're working in main.tscn, you can select and customize individual instances. But if you double-click OurPlatform.tscn in the FileSystem, you're opening the original platform scene to edit it. Changes you make there will affect all its instances, unless you've already customized those properties individually.

You've learned how to build a scene from nodes, save it, and reuse it inside another scene. The same approach works for platforms, enemies, collectibles, menus, and entire levels. Build something once, then use it wherever you need it.
