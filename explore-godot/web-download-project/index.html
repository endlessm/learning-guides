Download your project from web GodotDescarga tu proyecto desde Godot en la web

When you build in Godot in your browser, your project lives inside the browser, not in a folder on your computer. To share it, or to keep a copy, you download the whole project as one ZIP file.Cuando trabajas en Godot desde el navegador, tu proyecto vive dentro del navegador, no en una carpeta de tu computadora. Para compartirlo, o guardar una copia, descargas todo el proyecto como un solo archivo ZIP.

That ZIP is your own copy of your work. You can load it back into Godot on the web later to keep building or to play your game, even on a different computer. You can also give it to anyone with Godot, and they get the same project you have.Ese ZIP es tu propia copia de tu trabajo. Puedes volver a cargarlo en Godot en la web más tarde para seguir construyendo o jugar tu juego, incluso en otra computadora. También puedes dárselo a cualquiera que tenga Godot, y tendrá el mismo proyecto que tú.

What you'll doLo que vas a hacer

  1. Save your work and download the project as a ZIP.Guarda tu trabajo y descarga el proyecto como ZIP.
  2. Keep the ZIP somewhere safe, or share it.Guarda el ZIP en un lugar seguro, o compártelo.
  3. Load the ZIP back into Godot on the web when you want to keep working.Vuelve a cargar el ZIP en Godot en la web cuando quieras seguir trabajando.

Download the project sourceDescarga el código del proyecto

Godot packs your whole project into a and hands it to your browser as a download.Godot empaqueta todo tu proyecto en un y se lo entrega a tu navegador como una descarga.

  • Save your work first with Scene → Save All Scenes. Godot packs what's saved, so unsaved changes would be left out.Primero guarda tu trabajo con Escena → Guardar Todas las Escenas. Godot empaqueta lo que está guardado, así que los cambios sin guardar se quedarían fuera.
  • Open Project → Tools.Abre Proyecto → Herramientas.
  • Click Download Project Source.Haz clic en Download Project Source. Esta opción aparece en inglés aunque Godot esté en español.

Keep the ZIP safe, or share itGuarda el ZIP en un lugar seguro, o compártelo

Your browser saves the ZIP the same way it saves any other download, so look for it wherever your downloaded files go.Tu navegador guarda el ZIP igual que cualquier otra descarga, así que búscalo donde se guardan tus archivos descargados.

  • Leave the file zipped. Godot opens the ZIP itself.Deja el archivo comprimido. Godot abre el ZIP por sí mismo.
  • Keep a copy somewhere safe outside this browser.Guarda una copia en un lugar seguro fuera de este navegador.
  • To share it, send it the way you usually share files.Para compartirlo, envíalo como sueles compartir archivos.
  • If the person you give it to uses Godot installed on their computer, they open the and either click Import and choose the ZIP, or drag the ZIP straight onto the Project Manager window. If they use Godot on the web, they follow step 3.Si la persona a quien se lo das usa Godot instalado en su computadora, abre el y hace clic en Importar y elige el ZIP, o arrastra el ZIP directamente a la ventana del Administrador de Proyectos. Si usa Godot en la web, sigue el paso 3.

Why not Pack Project as ZIP?¿Por qué no Empaquetar proyecto como ZIP?

The Project menu also has Pack Project as ZIP..., and it works well in Godot on a computer. In Godot on the web, though, it saves the ZIP inside the browser's own storage for Godot, where you can't find it to send. Download Project Source makes the same ZIP and hands it to your browser as a regular download instead.El menú Proyecto también tiene Empaquetar proyecto como ZIP..., y funciona bien en Godot instalado en una computadora. Pero en Godot en la web guarda el ZIP dentro del almacenamiento del navegador para Godot, donde no lo puedes encontrar para enviarlo. Download Project Source crea el mismo ZIP y se lo entrega a tu navegador como una descarga normal.

Load your project back into web GodotVuelve a cargar tu proyecto en Godot en la web

Godot on the web saves your project inside this browser, on this computer. If the browser's data gets cleared, the project is gone, and a different computer or browser starts with an empty project list. Your downloaded ZIP doesn't depend on any of that, so you can bring your work back from it.Godot en la web guarda tu proyecto dentro de este navegador, en esta computadora. Si se borran los datos del navegador, el proyecto desaparece, y otra computadora u otro navegador empiezan con la lista de proyectos vacía. Tu ZIP descargado no depende de nada de eso, así que puedes recuperar tu trabajo desde él.

Step 3Paso 3

Open the ZIP in Godot on the webAbre el ZIP en Godot en la web

This works the same for you or for anyone you shared the ZIP with. The ZIP goes in on the Loader page, before the editor starts.Funciona igual para ti o para cualquiera con quien compartiste el ZIP. El ZIP se carga en la página Loader, antes de que arranque el editor. Esta página aparece en inglés.

  • Open Godot on the web in your browser. If the editor is already running, reload the page so the Loader tab shows.Abre Godot en la web en tu navegador. Si el editor ya está abierto, recarga la página para que aparezca la pestaña Loader.
  • Next to Preload project ZIP, click Choose File and pick the ZIP.Junto a Preload project ZIP, haz clic en Choose File y elige el ZIP.
  • Click Start Godot Editor. The editor opens with your saved project loaded.Haz clic en Start Godot Editor. El editor se abre con tu proyecto guardado ya cargado.
