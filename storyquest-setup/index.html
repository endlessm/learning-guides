Use the Backstitch launcher to open your kit in GodotUsa el lanzador de Backstitch para abrir tu kit en Godot

Why are we opening Godot this way?¿Por qué abrimos Godot de esta manera?

This next step is a little different from how you would normally download and open Godot. The StoryQuest Kit comes with Godot, your project files, and an extra collaboration tool called Backstitch, so you'll use the Backstitch launcher to open them together.Este siguiente paso es un poco diferente de cómo descargarías y abrirías Godot normalmente. El kit de StoryQuest incluye Godot, tus archivos de proyecto y una herramienta de colaboración extra llamada Backstitch, así que usarás el lanzador de Backstitch para abrirlos juntos.

If it asks whether you want to install an update, type Y for yes or N for no. It is generally good to keep Backstitch updated.Si te pregunta si quieres instalar una actualización, escribe Y para sí o N para no. En general, conviene mantener Backstitch actualizado.

Always open from the launcherAbre siempre desde el lanzador

The launcher is what loads Backstitch and your StoryQuest files. If you open Godot separately it will not include Backstitch. So from now on this is how you should open your project. Try closing everything and reopening from the launcher file once more, so you get used to it.El lanzador es lo que carga Backstitch y tus archivos de StoryQuest. Si abres Godot por separado no incluirá Backstitch. Así que, a partir de ahora, así es como deberías abrir tu proyecto. Prueba a cerrar todo y volver a abrir desde el archivo del lanzador una vez más, para que te acostumbres.

So, what is Backstitch?Entonces, ¿qué es Backstitch?

Backstitch is a tool that works alongside Godot while you build your StoryQuest. It keeps a history of your changes, lets you return to earlier versions, helps teammates work on separate branches (versions of the project) and bring their work back together. With Backstitch, you can also create playable web links for sharing and testing as you build. This image below shows you what Godot looks like with Backstitch running inside the engine. Other than this extra feature you are using a regular copy of Godot.Backstitch es una herramienta que funciona junto a Godot mientras construyes tu StoryQuest. Guarda un historial de tus cambios, te permite volver a versiones anteriores, y ayuda a que los compañeros trabajen en ramas separadas (versiones del proyecto) y junten su trabajo. Con Backstitch, también puedes crear enlaces web jugables para compartir y probar mientras construyes. La imagen de abajo te muestra cómo se ve Godot con Backstitch funcionando dentro del motor. Aparte de esta función extra, estás usando una copia normal de Godot.

You can learn more about this collaboration tool at backstitch.dev if you're interested.Puedes aprender más sobre esta herramienta de colaboración en backstitch.dev si te interesa.

Making more than one StoryQuest project?¿Hacer más de un proyecto de StoryQuest?

Each StoryQuest project should have its own copy of the kit in a separate folder. To start another project, extract the files from the .zip again into a new folder and give it a clearly different name. This keeps your projects separate from one another.Cada proyecto de StoryQuest debería tener su propia copia del kit en una carpeta separada. Para empezar otro proyecto, extrae los archivos del .zip de nuevo en una carpeta nueva y dale un nombre claramente distinto. Así mantienes tus proyectos separados unos de otros.

For example, you might already have a personal StoryQuest and later want to join a teammate's project. Make a second folder for the team project and extract a new copy of the kit into it so your personal projects stay separate.Por ejemplo, quizás ya tengas un StoryQuest personal y más adelante quieras unirte al proyecto de un compañero. Crea una segunda carpeta para el proyecto del equipo y extrae en ella una copia nueva del kit para que tus proyectos personales se mantengan separados.

Joining someone else's projectUnirse al proyecto de otra persona

Once you've set up a second folder and copy of the StoryQuest kit on your computer, go ahead and open that new folder the same way you opened your first project: double-click the Backstitch launcher to open it in Godot.Una vez que hayas preparado una segunda carpeta y copia del kit de StoryQuest en tu ordenador, abre esa carpeta nueva de la misma forma en que abriste tu primer proyecto: haz doble clic en el lanzador de Backstitch para abrirla en Godot.

In Godot, open the plugin on the right and this time choose Load Existing Project instead of Create New Project. Paste in the your teammate shares with you. That folder is now connected to your team's Backstitch project. Try and give Backstitch a moment to load this new project it may take a few seconds.En Godot, abre el plugin de a la derecha y esta vez elige Load Existing Project en vez de Create New Project. Pega el que tu compañero comparta contigo. Esa carpeta ya está conectada al proyecto de Backstitch de tu equipo. Dale a Backstitch un momento para cargar este proyecto nuevo, puede tardar unos segundos.

Set up folders for your StoryQuestPrepara carpetas para tu StoryQuest

Main idea: It's a really good idea to keep your own work together in a separate folder from the rest of the kit.Idea principal: Es muy buena idea mantener tu propio trabajo junto en una carpeta separada del resto del kit.

Optional: The StoryQuest Kit includes a quick setup tool that can create a starter folder for you, along with a few simple example scenes and folders you can borrow from.Opcional: El kit de StoryQuest incluye una herramienta de configuración rápida que puede crear una carpeta inicial para ti, junto con algunas escenas y carpetas de ejemplo sencillas que puedes tomar prestadas.

The tool asks for your StoryQuest name, so you can come back to this later once you have one. And remember that the folder and scene structure it creates is only an example. You don't need to use those scenes, mechanics or that structure at all. Feel free to keep what is useful and change or remove the rest to fit what you want to build and what matches your StoryQuest plan.La herramienta te pide el nombre de tu StoryQuest, así que puedes volver a esto más adelante cuando tengas uno. Y recuerda que la estructura de carpetas y escenas que crea es solo un ejemplo. No necesitas usar esas escenas, mecánicas ni esa estructura en absoluto. Siéntete libre de conservar lo que te sirva y cambiar o quitar el resto para que encaje con lo que quieras construir y con tu plan de StoryQuest.
